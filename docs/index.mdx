## What you get

- Token usage, cost, latency, and errors for each trace and span.
- Standard OTLP/HTTP ingest for first-party SDKs and your OpenTelemetry stack.
- Environment-level controls for input and output capture.
- SDK masking and server-side redaction before storage.

The wire format is OpenTelemetry. You can keep your instrumentation and use standard OTLP/HTTP instead of a proprietary trace protocol.

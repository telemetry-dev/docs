telemetry.dev records what your AI application does. Each run becomes one trace that shows every model call, tool call, and step in order, with the tokens, cost, latency, and errors of each one.

telemetry.dev is built on OpenTelemetry. The SDKs send standard OTLP/HTTP, and so can the OpenTelemetry setup you already run.

## What you can do

- **Debug a single run.** Open a trace to read each model call's input and output, each tool's arguments and result, and the error that ended a failed run.
- **Follow a conversation.** Traces that share a session ID are grouped into one session.
- **Track cost and usage.** Tokens and cost are calculated per span and added up per trace, session, model, and user.
- **Keep sensitive data out.** Turn off prompt and response capture per environment, and redact secrets and personal data before storage.
- **Measure quality.** Run a prompt version or your code on a dataset, score the replies with LLM judges, code checks, and reviewers, and compare the results.

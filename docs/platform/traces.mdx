A trace is one request through your application. Each step inside it, such as a model call, a tool call, or an agent step, is a span. Use the trace explorer to find failed or slow requests and to see what each model call received and returned.

## Find a trace or span

Select **Traces** in the project sidebar. Use the **Traces** and **Spans** switch above the table to list whole requests or single operations.

Both lists have these filters:

| Filter | What it does |
| --- | --- |
| Search | Matches trace names or span names. It does not search prompt or response content. |
| Status | Shows **All statuses**, `success`, or `error`. |
| Environment | Lists up to 100 environment names from your telemetry. |
| Framework | Lists the frameworks detected in your telemetry. |
| Date range | Shows **Last 7 days**, **Last 30 days**, or **Last 90 days**. The default is 30 days. |
| Session | Select a value in the **Session** column. A chip shows the filter; select it to clear the filter. |
| User | In the trace list, select a value in the **User** column. A chip shows the filter; select it to clear the filter. |

A row of the **Breakdown** table on the [Overview](/platform/analytics#break-traces-down-by-a-dimension) can also open the span list filtered by **Model**, **Provider**, or **Operation**, with a chip for that filter.

The filters are part of the page URL, so you can bookmark or share a filtered view.

The table shows one page at a time. Use the pager below it to move between pages, and **Rows per page** to show 25, 50, or 100 rows.

### Trace columns

The trace list shows **Date** and **Trace**, plus these columns: **Input**, **Output**, **Duration**, **Tokens**, **Cost**, **Spans**, **Models**, **Session**, **User**, and **Environment**.

- **Input** and **Output** show the start of the request's prompt and reply.
- **Duration** shows the time to first token when you hover over it, if the trace has that value.
- **Tokens** shows input and output tokens. Hover over it for cache-read and reasoning tokens.
- **Spans** shows the span count and the number of spans with errors.

### Span columns

The span list shows **Date**, **Type**, and **Name**, plus these columns: **Model**, **Tool / Agent**, **Session**, **Service**, **Environment**, **Status**, **Duration**, **Tokens**, and **Cost**.

Select a span row to open its trace with that span selected.

### Choose columns

Select **Columns** to show or hide columns. **Environment** is hidden by default in both lists, and **Service** is hidden by default in the span list. Your browser keeps the choice for later visits.

## Inspect a trace

Select a trace row to open the trace. The header shows the trace's name, its status, and its ID, with a button to copy the ID. Below the header are two tabs:

- **Trace**: the span tree, with a bar for each span on a shared time axis, nested under its parent.
- **Metadata**: the trace's details. **Trace** lists the **Trace ID**, **Started**, **Duration**, **Turns**, **Spans**, and **Errors**. **Usage** lists the **Models**, the token counts, and the **Cost**. **Source** lists the **Agent**, **Service**, **Environment**, **Framework**, **Session**, and **User**. The trace's metadata follows, if it has any.

Above the span tree, **Find spans** searches span names; press `Enter` for the next match. **Filters** hides span types or shows **Errors only**. Select **Expand all** or **Collapse all** to open or close the tree.

### Move through spans with the keyboard

Focus the span tree, then use these keys:

| Key | Action |
| --- | --- |
| `↓` | Select the next span |
| `↑` | Select the previous span |
| `Home` or `End` | Select the first or last span |
| `→` | Expand a span, or select its first child |
| `←` | Collapse a span, or select its parent |

### Read a span

Select a span to open its panel. The panel header shows the span's type and name, with **Previous span** and **Next span** buttons. Below it, the panel shows these sections when the span has data for them:

- **Error**: the error message and details, for a failed span.
- **Metrics**: when the span started, its duration, and its offset from the start of the trace. Model calls also show **First token**, **Output speed**, **Cost**, and their tokens.
- A section for the kind of span, such as **Model call** with the **Requested model**, **Response model**, **Provider**, **Finish reason**, and **Response ID**, or **Tool call**, **Agent**, or **MCP**.
- **Input** and **Output**: the prompt and the reply. A tool call shows **Arguments** and **Result** instead. Where a section offers them, select **Pretty** for a formatted view or **JSON** for the stored value.
- **Events**: the span events and their attributes.
- **Attributes**: the span attributes.

A **Truncated** badge marks a value that the panel shows only in part.

If prompt and response capture is off for the environment, the **Input** and **Output** sections say that capture is off, and the span name is `[REDACTED]`. Read [What capture-off removes](/platform/privacy#what-capture-off-removes).

## Follow a conversation

Select **Sessions** in the project sidebar to list conversations. A session groups the traces that share a session ID. To set one, read [Add user, session, and metadata](/sdk/typescript#add-user-session-and-metadata) for TypeScript or [Python](/sdk/python#add-user-session-and-metadata).

Select **24h**, **3d**, **7d**, or **30d** to set the time range. You can search by session ID or trace name and filter by agent, user, or model. The list shows each session's **Agent**, **Model**, **Customer**, **Turns**, **Tokens**, **Cost**, and **Last active** time.

Select a session to see its **Customer**, **Agent**, **Models**, **Started** time, **Duration**, **Tokens**, and **Cost**, a list of its **Turns**, and each turn of the conversation. Select **Open in Traces** to list the session's traces, or **Open trace** if the session has one trace.

## Read logs

Select **Logs** in the project sidebar. The table shows **Date**, **Level**, **Entity**, **Message**, and **Data**.

The level filter starts at `error`. You can also select `warn`, `info`, `debug`, or **All levels**.

The table loads the newest 100 matching log records from the last 30 days, or from the retention period if that is shorter. It has no further pages. The search box filters only the message previews in those loaded records.

Select a row to open the log details, with the full message, level, service, environment, the related trace, and the log's data. If the log has trace context, select **Trace** to open the trace with the log's span selected.

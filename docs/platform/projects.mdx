A project holds the telemetry for one application, with its own API keys, privacy settings, and retention. Projects belong to an organization, which holds members, billing, and usage. Use [environments](/platform/environments) inside one project to separate production from staging.

## Sign in and get an organization

Sign in with an email address and a password. **Continue with GitHub** and **Continue with Google** appear when the deployment has those providers set up.

After you verify your email address, telemetry.dev creates an organization named after you, such as `Ada's workspace`, and makes you its owner.

If an invitation for your email address is waiting, telemetry.dev does not create that organization. It opens onboarding instead. There you can **Accept** or **Decline** each invitation, or select **Create an organization**.

To add another organization later, open the organization switcher in the sidebar and select **New organization**. You can own up to 5 organizations.

## Create a project

Any member of the organization can create a project.

<Steps>
  <Step title="Open the project list">
    Select **All projects** in the sidebar.
  </Step>
  <Step title="Name the project">
    Select **Create project**. Enter a **Project name** of 1 to 100 characters, then select **Create project**.
  </Step>
  <Step title="Copy the API key">
    The **Project created** dialog shows a new API key named `default`. Copy it now; telemetry.dev does not show it again.
  </Step>
  <Step title="Open setup">
    Select **Go to setup** to connect an application.
  </Step>
</Steps>

Each plan limits the number of projects in an organization:

| Plan | Projects |
| --- | ---: |
| Free | 1 |
| Pro | 5 |
| Team | Unlimited |

At the limit, the project list shows **Upgrade to add projects** instead of **Create project**. It opens the **Billing** tab of the organization settings. Read [Plans and billing](/platform/billing#compare-plans).

## Connect an application

Select **Setup** in the project sidebar. Check the **Service name** and **Environment** fields, then select a tab and copy its snippet.

| Tab | What the snippet does |
| --- | --- |
| Vercel AI SDK | Installs `@telemetry-dev/ai-sdk` and turns on telemetry for `generateText` or `streamText` calls. |
| TanStack AI | Adds the `@telemetry-dev/tanstack-ai` middleware to `chat()` calls. |
| Claude SDK | Sends the Anthropic SDK's own OpenTelemetry spans through the telemetry.dev span processor. |
| Claude Platform | Gives the endpoint and header to enter as an OpenTelemetry destination in the Claude Console. |
| OpenTelemetry | Sets the OTLP/HTTP endpoint, the authorization header, the service name, and the environment resource attribute. |

**Service name** starts as the project name in lowercase with dashes. **Environment** starts as `production`. The snippets read the API key from the `TELEMETRY_DEV_API_KEY` environment variable.

The OpenTelemetry snippet shows `https://<your-ingest-host>` as the endpoint. For the hosted service, use `https://ingest.telemetry.dev`.

Some tabs have a **Read the guide** link. For full instructions, read the [Vercel AI SDK](/integrations/vercel-ai-sdk), [TanStack AI](/integrations/tanstack-ai), [Claude Platform](/integrations/claude-platform), or [OpenTelemetry](/sdk/opentelemetry#send-otlphttp-from-any-language) guide.

## Rename or delete a project

An organization owner or admin can rename or delete a project.

Select **Settings** in the project sidebar. On the **General** tab, change **Project name** and select **Save**, or select **Delete project** and confirm.

Deleting a project removes the project and its API keys, so the keys stop working at once. It also deletes the project's stored telemetry. You cannot undo it.

## Rename the organization

An organization owner or admin can rename the organization. Open the organization switcher, select **Organization settings**, and change **Organization name** on the **General** tab.

Only an owner can delete the organization. **Delete organization** on the same tab removes every project in it and all of their telemetry.

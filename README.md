# telemetry.dev docs

This repository contains the documentation for [telemetry.dev](https://telemetry.dev).

The site uses [Blume](https://blume-docs.com) and deploys at [docs.telemetry.dev](https://docs.telemetry.dev).

## Local development

Install the packages:

```sh
npm install
```

Start the local site:

```sh
npm run dev
```

Open [http://localhost:4321](http://localhost:4321).

## Build

Make the static site:

```sh
npm run build
```

The command writes the site to `dist/`.
